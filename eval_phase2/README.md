# eval_phase2 — Phase II Direct Evaluation (M.3 / R1.3)

Directly evaluates AnomalyGen's core LLM component (Phase II) on two axes:
**path-feasibility judgments** (CoT vs no-CoT) and **parameter-generation
quality**.  Complements `eval_labeling/` (M.2, label accuracy).

## Experiment A: Path Feasibility

### Design
- **Benchmark**: 40 HDFS merge points (26 feasible, 14 infeasible) split into
  28 simple (code-guard deterministic) and 12 complex (implicit state-flow).
- **Evaluation**: Feed each merge point to the CoT verifier (`v7`) and no-CoT
  baseline; compare predicted feasibility against ground truth.
- **Key Result**: CoT achieves **ACC 85.00%** vs no-CoT 81.08%, with gains
  concentrated on simple cases (89.29% vs 84.00%).

### Usage
```bash
cd AnomalyGen-main
export PYTHONPATH=$PYTHONPATH:$(pwd)

# (Re)build the benchmark dataset (optional — data already in eval_data/)
python eval_phase2/build_feasibility_dataset.py

# Run CoT variant
python eval_phase2/run_feasibility_eval.py --variant cot --sleep 0.5

# Run no-CoT variant
python eval_phase2/run_feasibility_eval.py --variant nocot --sleep 0.5

# Generate comparison report
python eval_phase2/run_feasibility_eval.py --report
```

## Experiment B: Parameter Quality

### Design
- **Data**: 207 parameter-slot instances sampled from four groups of generated
  logs (baseline, w/o-CoT, w/o-analysis HDFS, and ZooKeeper).
- **Type validity**: Each slot's semantic type is inferred from template context
  (hex, path, int, nodeid, etc.) and the filled value is validated against
  format rules.  Of 163 type-determinable slots, **162 passed** (validity
  = 0.994).  The single true LLM error: a zxid slot filled with decimal
  instead of hex.  10 of 11 failures are Drain parser artifacts.
- **Expert validation**: Two domain experts independently validated a stratified
  29-slot sample with **Cohen's κ = 1.0**.

### Usage
```bash
# Build parameter sample (optional — data already in eval_data/)
python eval_phase2/build_param_set.py --n 200 --seed 42

# Score parameter quality
python eval_phase2/run_param_eval.py

# Aggregate all metrics
python eval_phase2/compute_metrics.py
```

## Prerequisites
- Generated pipeline artifacts in `output/` and `output_v1/`.
- `models/config/config.json` with API key (for Experiment A only).
- `pip install openai` (for Experiment A only).
- Experiment B requires **no LLM calls** — pure rule-based scoring.
